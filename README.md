# 筋トレメモ RPE

「筋トレMEMO」を参考にした筋トレ記録アプリです。**RPE の入力**と**トレーニングプログラムの作成**に対応しています。
スマホのブラウザで動く Web アプリ（PWA）で、ホーム画面に追加すると普通のアプリのように使えます。

## 起動方法

### A. スマホで使う（おすすめ）

GitHub Pages で公開して、スマホのブラウザから開きます。最初に一度だけ設定が必要です。

1. このリポジトリの `main` ブランチにアプリのコードが入っていることを確認します
   （作業ブランチにある場合は、プルリクエストを作って `main` にマージします）。
2. GitHub のリポジトリページで **Settings → Pages** を開き、
   **Build and deployment → Source** を **「GitHub Actions」** に変更します。
3. **Actions** タブで「Deploy to GitHub Pages」が緑色（成功）になるまで数分待ちます。
   公開 URL は Settings → Pages の画面上部に表示されます。
   （このリポジトリの場合は `https://santori8931234-boop.github.io/-/` の予定です）
4. スマホでその URL を開き、ホーム画面に追加します。
   - **iPhone**：Safari で開く → 下部の共有ボタン（□↑）→「ホーム画面に追加」
   - **Android**：Chrome で開く → 右上の「︙」→「ホーム画面に追加」（または「アプリをインストール」）
5. ホーム画面の「筋トレメモ」アイコンから起動します。

> 以降は `main` に変更を push するたびに自動で再公開されます。
> 何度か開いたあとは、電波の弱いジムでもオフラインで起動できます。
> iPhone ではホーム画面のアプリと Safari でデータが別々になるため、**記録は毎回ホーム画面のアイコンから開いて**ください。

### B. パソコンで起動する（動作確認・開発用）

必要なもの：[Node.js](https://nodejs.org/) 20.19 以上（22 系推奨）

```bash
git clone https://github.com/santori8931234-boop/-.git training-memo
cd training-memo
npm install        # 初回のみ
npm run dev        # 開発サーバーを起動
```

ブラウザで **http://localhost:5173** を開くと使えます（終了は `Ctrl + C`）。

同じ Wi-Fi のスマホから試したい場合：

```bash
npm run dev -- --host
```

ターミナルに表示される `Network: http://192.168.x.x:5173/` をスマホのブラウザで開きます。

本番と同じ状態で確認したい場合：

```bash
npm run build      # dist/ に出力
npm run preview    # http://localhost:4173 で確認
```

`dist/` フォルダはそのまま任意の静的ホスティング（Netlify、Cloudflare Pages など）に置いても動きます。

## 使い方

画面下のタブで 5 つの画面を切り替えます。

| タブ | できること |
| --- | --- |
| 📅 カレンダー | トレーニングした日の確認、日付を選んで記録、次のプログラムの開始 |
| ✏️ 記録 | 今日のトレーニングを記録 |
| 📋 プログラム | トレーニングプログラムの作成・開始 |
| 📈 分析 | 推定1RM・重量の推移、体重、RPE計算機 |
| ⚙️ 設定 | タイマー、種目の管理、バックアップ |

### 1. トレーニングを記録する

1. **✏️ 記録** タブを開きます（カレンダーで日付を選んで「記録する」でも可。同じ日付を 2 回タップしても開きます）。
2. **「＋ 種目を追加」** → 部位を選ぶ → 種目をタップ。
   一覧にない種目は、下の入力欄に名前を入れて「追加」で作れます。
3. セットごとに **kg / 回数 / RPE** を入力します。
   - 前回その種目をやっていれば、前回と同じセット数が用意され、**薄い文字で前回の値**が入っています。
   - 自重種目（懸垂など）は kg 欄に加重した重さだけ入れます（加重なしなら空欄で OK）。
4. セットが終わったら右端の **✓** をタップします。
   - 空欄のまま ✓ を押すと、薄い文字の値（前回値・推奨値）がそのまま記録されます。
   - **休憩タイマー**が自動で始まり、時間になると音とバイブで知らせます（−15 / +15 秒で調整、「終了」で止める）。
5. 必要に応じて体重・メモを入力します。**保存ボタンはありません**。入力した時点で自動保存されます。

#### 便利な操作

| 操作 | 方法 |
| --- | --- |
| 前のセットと同じ内容にする | 2セット目以降の **「⧉ 前セット」** をタップ |
| 同じ内容のセットを増やす | **「⧉ 前セットをコピーして追加」** をタップ |
| 空のセットを増やす | **「＋ セット」** をタップ |
| セットを削除 | 左端のセット番号（1, 2, 3…）をタップ |
| 種目の並べ替え・削除 | 種目名の右の ↑ ↓ ✕ |
| 前回の同じセットを見る | 各セットの下の「前回 85×5@8」の表示 |
| 種目の過去の記録を見る | 「前回 09/18：…　**履歴 ›**」をタップ（直近10回分） |
| 前回の日の内容を全部見る | 画面上部の **「🕘 前回のトレーニング」** をタップ |
| その日の記録を全部消す | 右上の 🗑 |

### 2. RPE の付け方

RPE（主観的運動強度）は「そのセットがどれくらいキツかったか」を 6〜10 の数字で表したものです。
記録画面の列見出し **「RPE ⓘ」** をタップすると目安が表示されます。

| RPE | 目安 |
| --- | --- |
| 10 | 限界。もう 1 回もできない |
| 9 | あと 1 回できた |
| 8 | あと 2 回できた |
| 7 | あと 3 回できた（バーが速く動く） |
| 6 | あと 4 回以上できた |

0.5 刻みで「8.5 = あと 1〜2 回」のように付けられます。
重量・回数・RPE から **推定1RM（e1RM）** が自動計算され、各セットの右に表示されます。

### 3. プログラムを作って使う

#### テンプレートで試す

1. **📋 プログラム** → **「テンプレート（RPE式 BIG3 週3回）を追加」**
2. **「使用する」** をタップ（カードに「使用中」と表示されます）
3. Day の **「今日開始」** をタップすると、その Day の種目・セットが今日の記録に入ります

#### 自分で作る

1. **「＋ 新しいプログラムを作成」** をタップ
2. 名前と説明を入力
3. Day ごとに **「＋ 種目を追加」** で種目を入れる（最初は 8回 @RPE8 × 3セット）
4. 各セットの **回数 / RPE / %1RM** を設定する
   - 例：トップセット 3回 @8、バックオフ 5回 @7 × 3
   - %1RM を入れた場合は RPE より %1RM が優先されます
   - 「＋ セット」で最後のセットと同じ目標のセットを追加、「−」で削除
5. **「＋ Day を追加」** で Day 2、Day 3… を追加（↑ で並べ替え、⧉ で Day を複製）
6. **「完了」** で戻り、**「使用する」** を押す

#### プログラムでトレーニングする

- 使用中のプログラムは、**カレンダー画面**に「次のプログラム（Day ○）」として表示されます。
  「○月○日に開始」を押すと記録画面が開きます。Day 1 → Day 2 → Day 3 → Day 1… と自動で進みます。
- 記録画面では各セットの下に **「目標 5回 @7 → 推奨 125kg」** と表示されます。
  - 推奨重量は **前回の推定1RM** と目標の回数・RPE から計算されます（丸め単位は設定で変更可）。
  - その日のセットを RPE 付きで ✓ すると、**その実績から残りのセットの推奨重量が計算し直されます**。
    調子が良ければ重く、悪ければ軽く自動調整されます（オートレギュレーション）。
  - 実際の RPE が目標より高い/低いと「目標RPE超過 / 未満」と表示されます。
- 初めての種目は推定1RMがないので推奨重量は出ません。1 回記録すると次回から表示されます。

### 4. 記録を振り返る（📈 分析）

- **種目**：種目を選ぶと、推定1RM・最大重量・ボリュームの推移グラフと、日付ごとの履歴を表示（日付をタップするとその日の記録へ）
- **体重・頻度**：体重の推移、週ごとのトレーニング日数（直近12週）、部位別のセット数（直近30日）
- **RPE計算機**：重量・回数・RPE を入れると推定1RM と「何回 @RPE いくつなら何 kg か」の表を表示

### 5. 設定（⚙️）

- **インターバルタイマー**：休憩時間（秒）、✓ で自動スタートするか
- **推奨重量**：丸め単位（2.5kg、1kg など。プレートの刻みに合わせる）
- **種目の管理**：名前・部位の変更、自重種目の設定、削除（記録で使った種目は削除不可）
- **データ**：バックアップの書き出し / 読み込み、全データ削除

## 機能一覧

- **記録**：カレンダー（部位別の色ドット）、重量 / 回数 / RPE（6〜10、0.5刻み）、推定1RM、完了チェック、休憩タイマー、体重・メモ
- **前回の記録**：前回値のヒント表示、セットごとの前回値、種目の履歴（直近10回）、前回の日のまとめ
- **コピー**：前セットをワンタップでコピー、同じセットを追加
- **RPE**：RTS 式 RPE 表で推定1RM を計算、RPE の目安表示、RPE 計算機
- **プログラム**：複数 Day、セットごとの目標回数 / RPE / %1RM、推奨重量の自動計算とオートレギュレーション、次の Day の自動表示、テンプレート
- **分析**：推定1RM / 最大重量 / ボリュームのグラフ、体重推移、週ごとの頻度、部位別セット数
- **その他**：オフライン動作、ホーム画面追加、JSON バックアップ

## よくある質問・注意点

**データはどこに保存される？**
スマホのブラウザの中（localStorage）だけです。サーバーには送信されません。
そのため、次の場合はデータが消えたり引き継げなかったりします。

- ブラウザの「履歴とWebサイトデータを消去」をした
- 機種変更した / 別のブラウザや別の端末で開いた
- iPhone で Safari で開いた場合とホーム画面のアイコンから開いた場合（データが別々になります）

→ **設定 →「バックアップを書き出す」** で定期的に JSON ファイルを保存しておき、
新しい端末では **「バックアップを読み込む」** で復元してください。

**URL が変わるとデータは？**
データは URL（ドメイン）ごとに保存されます。公開先を変えた場合はバックアップ → 読み込みで移してください。

**タイマーの音が鳴らない**
iPhone ではマナーモード中は音が鳴らないことがあります。画面をロックするとタイマーが止まる場合もあります。

**推奨重量が出ない**
プログラムから開始したセットで、かつその種目の過去の記録（重量と回数）がある場合に表示されます。

## 開発者向け

```bash
npm install
npm run dev        # 開発サーバー（http://localhost:5173）
npm test           # ユニットテスト（RPE 計算・集計）
npm run typecheck  # 型チェック
npm run build      # dist/ に本番ビルド
npm run preview    # ビルド結果の確認（http://localhost:4173）
```

- 技術構成：React 19 + TypeScript + Vite（外部の UI / グラフライブラリなし）
- デプロイ：`main` への push で `.github/workflows/deploy.yml` が GitHub Pages に公開

```
src/
├── App.tsx              画面切り替え・タブバー
├── lib/
│   ├── rpe.ts           RPE 表・推定1RM・推奨重量の計算
│   ├── stats.ts         履歴・集計
│   ├── store.ts         状態管理と localStorage への保存
│   ├── defaults.ts      初期種目・テンプレートプログラム
│   └── types.ts         データ型
├── views/               各画面（カレンダー・記録・プログラム・分析・設定）
└── components/          共通部品（数値入力・タイマー・グラフなど）
```
