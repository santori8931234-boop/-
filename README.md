# 筋トレメモ RPE

「筋トレMEMO」を参考にした、**RPE 入力**と**トレーニングプログラム作成**に対応したトレーニング記録アプリです。
スマホのブラウザで動く PWA で、ホーム画面に追加するとアプリのように使えます。データは端末内（localStorage）に保存されます。

## 主な機能

### 記録
- カレンダーでトレーニング日を部位別の色ドットで表示、日付をタップして記録
- 種目ごとに **重量 / 回数 / RPE（6〜10、0.5刻み）** を入力
- 各セットの **推定1RM（e1RM）** を RPE を考慮して自動計算
- 前回の記録を表示し、新しいセットに前回値をヒントとして表示
- 各セットの下に「前回の同じセット」の記録を表示、「履歴 ›」で種目の直近10回分を一覧
- 記録画面の上部「前回のトレーニング」で前回の日の内容をまとめて確認
- 「⧉ 前セット」で1つ上のセットの重量・回数・RPEをワンタップでコピー、「⧉ 前セットをコピーして追加」で同じ内容のセットを追加
- セット完了（✓）でインターバルタイマーが自動スタート（音・バイブで通知）
- 体重・日ごとのメモ・種目ごとのメモ

### RPE
- RTS 式 RPE 表（回数 × RPE → %1RM）で推定1RMを算出
- RPE 列の「ⓘ」で各 RPE の目安（あと何回できたか）を表示
- RPE 計算機：重量・回数・RPE から推定1RMと、回数×RPE ごとの目標重量表を表示

### プログラム
- 複数の Day からなるプログラムを作成（Day の追加・並べ替え・複製）
- 種目ごとにセット単位で **目標回数・目標RPE・%1RM** を設定
- 「今日開始」で Day の内容をその日の記録に展開
- **推奨重量を自動計算**：前回の推定1RM × 目標回数/RPE の %1RM。
  当日トップセットを完了すると、その実績 RPE から次のセットの推奨重量を再計算（オートレギュレーション）
- 目標 RPE を超えた/下回ったセットを表示
- 「使用中」のプログラムは次に行う Day をカレンダー画面に表示
- テンプレート「RPE式 BIG3 週3回」を収録

### 分析
- 種目ごとの推定1RM / 最大重量 / ボリュームの推移グラフと履歴
- 体重推移、週ごとのトレーニング日数、部位別セット数（直近30日）

### 設定
- 休憩時間、タイマー自動開始、推奨重量の丸め単位
- 種目の追加・名前変更・部位変更・自重種目設定・削除
- JSON でバックアップの書き出し / 読み込み

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm test         # ユニットテスト（RPE計算・集計）
npm run build    # dist/ に本番ビルド
```

技術構成: React 19 + TypeScript + Vite（外部 UI / グラフライブラリなし）

## 公開（GitHub Pages）

`main` ブランチへの push で `.github/workflows/deploy.yml` が GitHub Pages にデプロイします。
リポジトリの Settings → Pages → Source を「GitHub Actions」に設定してください。
iPhone では Safari で開き「共有 → ホーム画面に追加」でアプリとして使えます。
